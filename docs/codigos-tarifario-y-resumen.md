# Códigos ARS, tarifario pendiente y resumen diario · 5.34.0

En **Códigos ARS** o **Captura rápida** puede registrarse el PSS que el médico gestionó directamente. Indique el origen y una observación. El médico y el personal autorizado pueden hacer el primer registro; cambiar un código registrado sigue reservado a Administrador y Super Admin, con motivo e historial.

El código PSS es independiente del tarifario. La tabla muestra **Tarifario pendiente** cuando existe código sin tarifas vigentes. Desde captura puede elegir **Capturar con tarifario pendiente**, buscar el servicio e indicar el monto real reclamado. La reclamación se guarda **Pendiente de configuración**; no se radica hasta resolver la contratación. El monto vacío o cero no se reemplaza por una tarifa inventada.

**Modo soporte:** salga de «Ver como» para registrar o corregir códigos y reclamaciones. Hospitalización consulta ahora el consultorio explícito, permite seleccionar médico cuando hay varios y muestra reportes en lectura. Las vistas individuales de soporte no simulan asignaciones.

**Inteligencia de mercado:** se corrigió el acceso desde el dominio actual, la clasificación de errores y la información de salud de las fuentes. Se añadieron RSS directos de DiarioSalud y Resumen de Salud como alternativa a fallos de Google News. Las fuentes pueden fallar parcialmente sin borrar las noticias guardadas.

**Mi bandeja → Resumen diario:** presenta conteos de capturas incompletas, lotes por radicar, glosas y cobros por escalar, sin nombres de pacientes, NSS ni diagnósticos en el mensaje. Guarda destinatario y hora para el usuario autenticado.

Para el destinatario confirmado se prepara un resumen y una notificación interna todos los días a las **7:00 a. m., Santo Domingo**, sin duplicarlo durante el día. La entrega automática por WhatsApp **no está activada**: requiere conectar WhatsApp Business/API de Meta o un proveedor autorizado. El botón **Abrir WhatsApp (envío manual)** prepara el texto, sin marcarlo como enviado ni confirmar entrega.
